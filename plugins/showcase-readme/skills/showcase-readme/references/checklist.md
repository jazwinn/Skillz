# Review checklist

Top of page
- [ ] Pitch says what it is and why it is hard in one sentence
- [ ] GIF loads, is under ~5 MB, shows the headline feature within the first 5 seconds
- [ ] GIF caption states hardware and any time compression
- [ ] Every badge is true

Evidence
- [ ] Every number traces to a command run this session, a file in the repo, or the user
- [ ] Test count was listed from the test binaries, not guessed
- [ ] Nothing from abandoned branches or stale notes
- [ ] Known limitations / current bottleneck stated

Engineering zone
- [ ] Mermaid diagrams use real class/file names and render (no syntax errors)
- [ ] Directory table matches the actual tree
- [ ] Build and run commands are copied from what actually works
- [ ] Every fact from the previous README is still present somewhere

Presentation
- [ ] No section is padding; empty sections removed
- [ ] Long reference material is in `<details>`
- [ ] Relative links and image paths resolve from the repo root
- [ ] Reads cleanly in GitHub dark mode
